# Experiment 10 — User Authentication (UI Demonstration)

A standalone Flutter app demonstrating a polished email/password login form, validation, progress, and success states. Sign-in is simulated; no credentials are transmitted or saved.

A real app should use Firebase Authentication for passwords rather than storing passwords in Firestore.

## Run

From this folder:

```sh
flutter pub get
flutter run -d windows
# or: flutter run -d chrome
```
